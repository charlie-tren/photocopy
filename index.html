Photocopy

← Other Projects
One image a day, each generated from a description of the last

words shared is how much the recent descriptions reuse the same words.

pictures different is how far apart the recent images are in structure. 0 is identical, about 32 is two unrelated pictures.

Both averaged over the last five frames. Nothing acts on them.

The model only ever sees the previous picture. Its description becomes the next prompt. Nothing else carries over.
